Opis szczegółowy

Główne okno aplikacji MazeMotion.

Zarządza układem interfejsu: panelem gry (2D/3D), panelem wykresów oraz paskiem narzędzi. Obsługuje połączenie z Arduino przez port szeregowy, przełączanie trybu wizualizacji i zmianę języka interfejsu.
