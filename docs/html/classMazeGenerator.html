Opis szczegółowy

Klasa odpowiedzialna za generowanie labiryntu i wyznaczanie punktu docelowego.

Generuje labirynt metodą Recursive Backtracking (DFS), zapewniającą dokładnie jedną ścieżkę między dowolnymi dwoma komórkami. Udostępnia listę ścian jako znormalizowane prostokąty (0.0 – 1.0) oraz wyznacza najdalszą komórkę od startu za pomocą BFS.

◆ getWalls()

QVector< QRectF > MazeGenerator::getWalls ( )

Zwraca listę ścian labiryntu jako prostokąty w znormalizowanych współrzędnych.

Każda ściana reprezentowana jest jako QRectF o współrzędnych z zakresu 0.0 – 1.0. Dla uniknięcia duplikatów, w głównej pętli uwzględniane są tylko ściany górne i lewe każdej komórki, a krawędzie dolna i prawa siatki dodawane są osobno.

Zwraca
Wektor prostokątów reprezentujących ściany

void MazeGenerator::makePath ( int  row,
int  col 
)

Rekurencyjnie drąży ścieżki w labiryncie (algorytm DFS).

Odwiedza komórkę, losowo miesza kolejność kierunków, a następnie dla każdego nieodwiedzonego sąsiada usuwa ścianę i rekurencyjnie kontynuuje drążenie.

Parametry
[in]row- Wiersz aktualnej komórki
[in]col- Kolumna aktualnej komórki
