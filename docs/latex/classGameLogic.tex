\doxysubsection{Opis szczegółowy}
Klasa zawierająca logikę gry — fizykę kulki, kolizje i zarządzanie labiryntem. 

Oddzielona od warstwy renderowania, dzięki czemu może być współdzielona przez widgety 2D (\doxylink{classGameWidget}{Game\+Widget}) i 3D (\doxylink{classGameWidget3D}{Game\+Widget3D}).
