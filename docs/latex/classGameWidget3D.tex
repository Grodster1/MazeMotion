\doxysubsection{Opis szczegółowy}
Widget renderujący scenę gry w 3D z wykorzystaniem Open\+GL 3.\+3 Core Profile. 

Wykorzystuje nowoczesny potok renderowania oparty na shaderach z oświetleniem Phonga, bufory wierzchołków (VBO/\+VAO) oraz wielopróbkowanie (MSAA 4x). Logika gry (fizyka, kolizje, labirynt) delegowana jest do klasy \doxylink{classGameLogic}{Game\+Logic}, dzięki czemu widget odpowiada wyłącznie za wizualizację.
